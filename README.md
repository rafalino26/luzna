# Luzna storefront

Prototype UI Next.js App Router. Produk, harga, dan foto bersifat ilustratif.
Pencarian, pemilihan ukuran, serta tas belanja berjalan di browser. Panel akun
dan checkout merupakan tampilan awal.

    npm install
    npm run dev

Buka http://localhost:3000.

## Foto konsep

produk Luzna saat materi asli sudah siap.

Bottom right: woman in an ivory abaya with matching hijab. Each one standing alone, framed from head to hem, centered in its own quadrant, soft warm beige plaster studio, elegant contemporary luxury textile photography, no text, no logo.
