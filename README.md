# Luzna storefront

Prototype UI Next.js App Router. Produk, harga, dan foto bersifat ilustratif.
Pencarian, pemilihan ukuran, serta tas belanja berjalan di browser. Panel akun
dan checkout merupakan tampilan awal.

    npm install
    npm run dev

Buka http://localhost:3000.

## Foto konsep

Foto demo versi Elegance in Sunnah ada di `public/*-sunnah.jpg`. Edit ImageGen
memburamkan fitur wajah dengan efek lembut, sambil mempertahankan kerudung,
tekstur kain, pose, pencahayaan, dan latar. Untuk katalog, tata letak empat
foto dan urutan hitam, olive, taupe, serta ivory juga dipertahankan.
